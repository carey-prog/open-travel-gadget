# 全国城际大交通参考（高铁 / 飞机 / 普速火车）

> 以下为常见线路的**参考性**说明，具体车次、时刻、票价以 12306、航司官网为准；节假日需提前购票。

## 高铁（G/D/C）特点
- 500–1000km 距离通常 3–6 小时，准点率较高，市区到站方便。
- 广深、长三角、京津冀、成渝等枢纽车次密集，可优先查「XX南/XX东/XX虹桥」站。
- 建议：提前 7–15 天购票；带老人/行李多可选一等座或靠过道座位。

## 飞机特点
- 1000km 以上或海岛（三亚等）常比高铁省时；需预留值机+安检 2 小时（国际更多）。
- 红眼航班便宜但影响首日游玩；机场到市区常 40–90 分钟，计入 D1 安排。
- 建议：比价时含「机场大巴/地铁」成本；雷雨季节关注延误险。

## 普速火车（Z/T/K）
- 夕发朝至适合省预算；硬卧/软卧适合长途夜行。
- 速度较慢，适合时间不敏感或高铁无直达的二三线目的地。

## 常见出发地 → 目的地 参考

### 广州/深圳 → 潮汕
- 高铁：广州南/深圳北 → 潮汕站，约 1.5–2.5 小时，车次多，推荐首选。
- 飞机：白云/宝安 → 揭阳潮汕机场，再打车至潮州/汕头约 50–70 分钟。
- 普速：较少作为首选。

### 北京/上海 → 西安
- 高铁：北京西/上海虹桥 → 西安北，约 4–6 小时。
- 飞机：约 2 小时飞行+往返机场时间，可比价。

### 北京/上海 → 成都
- 高铁：约 7–10 小时；飞机约 2.5–3 小时+机场通勤，常选飞机。
- 火车：Z 字头夕发朝至可选。

### 华东 → 桂林/厦门
- 高铁：杭州/上海 → 桂林/厦门北站，约 5–8 小时。
- 飞机：旺季厦门、桂林航线多，适合 3 日以内短假。

### 全国 → 三亚
- 飞机为主：多数城市无直达高铁，凤凰机场为枢纽。
- 冬季旺季机票上涨，建议提前 2–4 周预订。

### 成渝 → 重庆市区
- 高铁：成都东 → 重庆北/沙坪坝，约 1–1.5 小时，班次密集。

## 大交通规划原则（供行程生成）
1. 先列 2–3 种方式：高铁直达、飞机、普速火车（如适用），标注大致时长与价格区间。
2. 推荐一种「首选」并说明理由（时间/价格/舒适度）。
3. D1 安排需扣除「出发地→枢纽→目的地」通勤，避免首日景点过满。
4. 返程同理，最后一天预留前往机场/车站时间。
5. 不代订票务，在 warnings 中提示用户自行查询 12306/航司 App。
