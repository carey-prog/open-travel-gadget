# 潮汕旅游攻略（潮州 + 汕头）

> 默认高铁潮汕站抵达；古城步行+打车，不推荐自驾进潮州古城核心区。

## 枢纽
- 潮汕站：潮州、汕头、揭阳共用，到潮州古城约 25–35 分钟，到汕头小公园约 50–70 分钟
- 汕头站：直达汕头市区
- 揭阳潮汕机场：到潮州/汕头约 50–90 分钟

## 3 日经典
- D1：潮汕站 → 潮州古城牌坊街 → 广济桥夜景
- D2：开元寺 → 韩文公祠或龙湖古寨 → 工夫茶
- D3：汕头小公园 → 南澳岛半日或陈慈黉故居

## 核心 POI
- 牌坊街/广济桥/开元寺（潮州）
- 汕头小公园/南澳岛/陈慈黉故居
- 美食：牛肉火锅、蚝烙、肠粉；生腌需风险提示

## 跨市
潮州 ↔ 汕头打车约 1 小时；南澳大桥旺季易堵
